# Camind — Triết học & Khám phá tư duy

Ứng dụng web tương tác khám phá các yếu tố định hình nhận thức, tư duy và học tập của sinh viên dựa trên nền tảng triết học duy vật biện chứng (Mác – Ăngghen – Lênin).

## Tính năng chính
- **Mở đầu Cinematic**: Giới thiệu câu chuyện triết học với hiệu ứng chuyển cảnh mượt mà.
- **Hero Triết gia tương tác**:
  - Hồ sơ Karl Marx, Friedrich Engels, V.I. Lenin.
  - Tab chuyển đổi tự động lướt lên đầu khi chọn với Framer Motion spring physics.
  - Mốc lịch sử tương tác với hiệu ứng hover màu hổ phách (#b7791f).
  - Trích dẫn kinh điển, đóng góp lý luận mở rộng co giãn linh hoạt.
- **Cơ sở lý luận**: Hệ thống 4 thẻ nguyên lý nền tảng.
- **Dòng thời gian infographic (Timeline Milestones)**:
  - Bố cục xen kẽ trên/dưới theo trục trung tâm chuẩn thiết kế Figma.
  - Dòng chảy uốn lượn, connector pins và axis nodes vàng gradient.
- **Liên hệ thực tiễn**: Slide trình diễn 3 phần với điều hướng tiếp theo và bảng so sánh thực tế.
- **Bối cảnh triết học**: 4 góc nhìn triết học kinh điển (Socrates, Aristotle, Confucius, Descartes).
- **Chân trang (Footer)**: Bảng nguồn tài liệu tham khảo (References Modal) và phản hồi.

## Công nghệ sử dụng
- **React 19**
- **Vite 6**
- **Framer Motion**
- **Canvas Confetti & Lucide React**
- **Kantumruy Pro Font** (Google Fonts & Local TTF offline support)

npm install
